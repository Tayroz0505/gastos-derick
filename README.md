# Gastos do Derick

Site simples para anotar os gastos do Derick (valor + categoria, data automática) e ver um relatório por mês e categoria.

- Hospedagem: GitHub Pages
- Dados e login: Supabase (tabela `gastos`, criada com `supabase.sql`)
- Configuração: `config.js` (Project URL e chave anon/publishable do Supabase)
